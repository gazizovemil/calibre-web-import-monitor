Telegram secret files go here:

telegram_bot_token
telegram_chat_id

Do not add quotes or extra lines. Example file contents:

telegram_bot_token:
123456789:AAExampleOnlyDoNotUse

telegram_chat_id:
123456789

Optional API access token:

monitor_token

When this file exists, the status API and covers require the token.
Telegram buttons require it even when the rest of the API is open.

The bot token above is only a fake example. Use your real token from BotFather.
